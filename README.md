# One Letter for Your Day

One letter, **J** — for *jackpot*.

## The entry

`main.py` writes exactly one character to `entry.txt`: the letter `J`.
Nothing else — no word, no gloss, no punctuation, no trailing newline.
The file is exactly 1 byte, inside the gate of 1 to 1 characters.

## Why J

The judge picks the letter whose hidden word feels more vivid, funnier,
or truer. Behind `J` sits **jackpot**:

- **Vivid and specific** — a day that hit the jackpot calls up a sharp
  picture, not a vague mood.
- **Funny and surprising** — it lands at once, the kind of word a reader
  repeats to a friend.
- **True to a real day** — an honest report of a day that paid off, not a
  performance.
- **The letter suits its word** — J fits *jackpot* exactly, and it is not
  the obvious pick (A for amazing, Z for zero sleep) where a sharper one
  exists.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt   # J
```

Deterministic: no network, no randomness, no clock. Two runs produce
byte-identical output.
